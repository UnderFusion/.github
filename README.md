<details>
<summary><strong>About this repository</strong></summary>

This public `.github` repository provides shared GitHub configuration for repositories owned by **UnderFusion**.

- `.github/FUNDING.yml` defines the default **Sponsor** button pointing to [Ko-fi](https://ko-fi.com/underfusion).
- Repositories with their own `.github/FUNDING.yml` can override this default.
- This configuration doesn't change application code or licensing in individual projects.
